# 🔌 API Testing with REST Assured and JUnit

Study project focused on **REST API test automation using Java, REST Assured, and JUnit**.

The repository was created during my learning path in API testing and is maintained as a reference project in my QA automation portfolio.

> ⚠️ **Project Status**
>
> This is an older study project and uses tooling and dependency versions from the period when it was created.
>
> The repository is kept mainly as a historical reference of my studies in Java-based API test automation.

## 🛠 Tech Stack

- Java
- REST Assured
- JUnit
- Maven
- Eclipse

## 🎯 Project Purpose

The objective of this project was to practice fundamental REST API testing concepts, including:

- Sending HTTP requests
- Validating HTTP status codes
- Validating API responses
- Working with JSON responses
- Creating automated assertions
- Organizing API tests with JUnit
- Managing dependencies with Maven

## 📁 Project Structure

The main Maven project is located inside the `TesteAPI` directory.

```text
RESTAssuredJunit_TestandoAPI/
├── TesteAPI/
│   ├── src/            # Automated test source code
│   ├── pom.xml         # Maven dependencies
│   └── target/         # Generated build artifacts
├── .metadata/          # Eclipse workspace metadata
└── README.md
```

## ▶️ Running the Tests

Navigate to the Maven project directory:

```bash
cd TesteAPI
```

Then execute:

```bash
mvn test
```
